# EVERLOOM — Timeless Style. Modern Essence.

EVERLOOM is a luxury e-commerce web application featuring high-fashion aesthetic design, interactive canvas plasma engine, seamless slide-in bag drawer, responsive mobile/PC layouts, and zero-dependency vanilla architecture.

## 🚀 Quick Start (Local Server)
No build process required!

### Option 1: PowerShell
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Open [http://localhost:8085](http://localhost:8085)

### Option 2: Python
```bash
python -m http.server 8085
```
Open [http://localhost:8085](http://localhost:8085)

### Option 3: Node / NPX
```bash
npx serve -p 8085
```

## ⚡ Deployment

### Deploying to Vercel
1. Import this repository into Vercel.
2. Vercel automatically detects `index.html` and `vercel.json`.
3. Click **Deploy**.

### Deploying to GitHub / GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Select **main branch** as source and save.
